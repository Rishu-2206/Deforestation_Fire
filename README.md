# 🔥 Fire Classification Project

This project is made for the AICTE Internship (July 2025). It detects fire using a trained machine learning model.

---

## 📁 Project Files

- `Classification_of_Fire_Types_in_India_Using_MODIS_Data_ML_ipynb` → Main Jupyter notebook
- `app.py` → Python file to run web app
- `scaler.pkl` → File to scale the input data
- `modis_2021_India.csv`, `modis_2022_India.csv` and `modis_2023_India.csv` → Dataset files
